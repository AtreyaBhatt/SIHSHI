Reasoning server and local credential vault

Reasoning server

Must match a host in the extension manifest. The extension can reach this origin and nothing else.

Local credential vault

This is a demo vault, not a password manager. Values are stored unencrypted in chrome.storage.local, readable by anything with storage access to this browser profile. Chrome exposes no API for reading the real password manager, so this is the only way to demonstrate value_ref. Use throwaway test credentials.

The server never sees these. It returns value_ref: "user_saved:password" and the slot is resolved here, locally, at execution time.
